# Where people ask questions, and how to search each source

Today's date is in your context; put the month and year, or "past month", into the queries.
Replace `<niche>` with the industry phrase and 2 or 3 synonyms the audience actually uses.
Run several variations per source. Fetch promising threads and read the comments.

## Community Q&A

| Source | Query recipes | Notes |
|---|---|---|
| Reddit | `site:reddit.com <niche> "how do I"`, `site:reddit.com r/<subreddit> <niche> question`, `<niche> reddit <month year>` | Find the 2 to 5 subreddits first (`<niche> subreddit`). Sort threads by new. Comments hold follow-up questions. |
| Quora | `site:quora.com <niche>`, `<niche> quora <year>` | Dates are visible on answers. Skip answers that are obviously promotional. |
| Stack Exchange / Stack Overflow | `site:stackexchange.com <niche>`, `site:stackoverflow.com <tool name>` | Technical niches only. Newest tab shows recent questions. |
| Hacker News | `site:news.ycombinator.com <niche> "Ask HN"` | Startup, software, and tooling niches. |
| Industry forums | `<niche> forum`, `<niche> community questions` | Many trades have one dominant forum (contractors, dentists, agencies, Shopify sellers). Find it and read the newest 2 pages. |
| Facebook groups, Slack, Discord | Usually not reachable by search. Ask the user to paste recent posts if these are the main hangouts. | Say explicitly when they were not covered. |

## Search engines

| Source | How | Notes |
|---|---|---|
| Google "People also ask" | Search the core terms and record the PAA questions; also search `<niche> questions`, `<niche> faq`, `<niche> "people also ask"` | PAA is not dated, so mark these as evergreen unless the question references something recent. |
| Google autocomplete style | `<niche> how to`, `<niche> why does`, `<niche> vs`, `<niche> cost`, `<niche> worth it`, `best <niche> for` | Great for intent coverage. |
| Google Trends | `trends.google.com` for rising queries in the niche | Fetch may fail; if so, say so. |
| Answer-the-public style tools | Only if the user has access; do not assume. | |

## Video and social

| Source | Query recipes | Notes |
|---|---|---|
| YouTube | `site:youtube.com <niche> <month year>`, then fetch video pages; comments often contain questions. | Titles of recent videos reveal what creators think the audience wants; comments reveal what it actually asks. |
| X / Twitter | `site:x.com <niche> "anyone know"`, `<niche> twitter thread <month year>` | Often blocked without login. Note the gap. |
| LinkedIn | `site:linkedin.com/posts <niche>`, `site:linkedin.com/pulse <niche>` | B2B niches. Comments are the question source. |
| TikTok / Instagram | Rarely searchable; ask the user for screenshots or exported comments. | |

## Buyers and customers

| Source | Query recipes | Notes |
|---|---|---|
| Review sites | `site:g2.com <category>`, `site:capterra.com <category>`, `site:trustpilot.com <competitor>`, Amazon reviews for physical products | "Cons" and 3-star reviews are questions in disguise: "I wish it did X" means people ask "can it do X". |
| App store reviews | `site:apps.apple.com <app>`, Google Play listing | Consumer apps. |
| Competitor FAQ and help centers | `site:<competitor>.com faq`, `site:<competitor>.com help` | Shows what buyers ask before and after purchase. |
| Product Hunt, G2 discussions | `site:producthunt.com <niche>` | Launch comments contain "does it support..." questions. |
| Podcasts and newsletters | `<niche> podcast <month year>`, `<niche> newsletter` | Episode titles and listener Q&A segments. |

## The user's own data (ask for it)

Support inbox, sales call notes, chat transcripts, webinar Q&A, and search terms on their site
are the best source of all. If the user can export any of these, read them first and treat
them as the highest-weight signal.

## Recording format

Keep a scratch table while gathering:

```
| # | Question (verbatim) | Source | URL | Date | Engagement | Asker | Intent |
```

Collapse duplicates but count them: five people asking the same thing in different words is
the strongest signal you will find.
