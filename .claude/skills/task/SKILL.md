description: Передать задачу агенту нужного проекта. Использование — /task <проект> <задача>, например /task zerdeli добавь страницу «Вакансии».
argument-hint: <проект> <задача>
---

Пользователь передал задачу через `/task`. Аргументы: `$ARGUMENTS`.

Разбери их так: первое слово — проект (синонимы в таблице `CLAUDE.md` хаба и в
`projects/registry.json`), всё остальное — текст задачи.

1. Определи агента по проекту: zerdeli → `zerdeli-dev`, aqbota и его приложения
   → `aqbota-dev`, torge → `torge-dev`, keysora → `keysora-dev`, qep → `qep-dev`,
   nextjs-boilerplate / qrgpt → `web-dev`. Если проект не распознан — спроси
   одним вопросом, не угадывай.
2. Убедись, что репозиторий проекта есть на диске (пути — в `CLAUDE.md` хаба).
   Нет локально — предложи `scripts/clone.sh <проект>`; в облаке подключи
   через `add_repo` и склонируй в `/home/user/<dir>`.
3. Вызови агента инструментом Agent. В промпте передай: текст задачи дословно,
   абсолютный путь к репозиторию и просьбу вернуть отчёт по формату агента.
4. Когда агент закончил — перескажи результат своими словами: что сделано, что
   проверено, что осталось. Для изменений в 3+ файлах предложи запустить
   `project-reviewer`.
