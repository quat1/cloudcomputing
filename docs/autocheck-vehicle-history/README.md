# История авто (Autocheck): письмо, PRD, аналитика

Пакет документов по запуску проверки истории авто через B2B API Autocheck в приложении.

| Файл | Что внутри |
|---|---|
| `00-rezyume.md` | Резюме: ответ по оплате, три варианта, рекомендация, допущения, источники |
| `01-pismo-istoriya-avto.md` | Письмо руководству: контекст, три варианта оплаты, рекомендация, экономика, риски, решения, следующие шаги |
| `02-prd-istoriya-avto.md` | PRD: проблема, цели, не-цели, пользовательские истории, требования P0/P1/P2 с критериями приёмки, метрики, открытые вопросы, фазы |
| `03-tracking-events.md` | Дизайн событий аналитики и места внедрения. План `.telemetry/` в репозитории ещё не заведён |
| `04-cjm.html`, `04-cjm.md` | CJM покупателя авто с пробегом: «как сейчас» и «как будет с Autocheck», кривая эмоций, кто платит, метрики, таблица «что меняется». Опубликованная страница: https://claude.ai/artifact/AX3MLmN6YABCVFAGRtnhVT |

Источник по API: техническая инструкция «Подключение к Autocheck B2B API» (PDF, 14 страниц).
